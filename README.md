# Healthcare-Analytics-Project

## Project Overview
This project analyzes healthcare data to understand patient demographics, medical conditions, hospital admissions, billing amounts, and test results.

## Tools Used
- Python — Data cleaning
- MySQL — Data analysis and SQL queries
- Power BI — Interactive dashboards and visualizations

## Key Performance Indicators (KPIs)
- Total Patients
- Total Billing Amount
- Average Billing Amount
- Average Length of Stay

## Dashboard Pages
- Healthcare Executive Summary
- Billing and Admission Analysis
- Patient and Test Results Analysis

## Dataset
The project uses a healthcare dataset containing patient demographics, medical conditions, admission details, billing information, medications, and test results.

## Project Files
- `healthcare_project.pbix` — Power BI report
- `Healthcare_Analytics_Project.pdf` — Dashboard PDF

## Project Objective
To use data analytics tools to explore healthcare trends and present useful insights through interactive dashboards.
